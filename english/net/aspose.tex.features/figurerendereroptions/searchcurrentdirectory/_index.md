## FigureRendererOptions.SearchCurrentDirectory property

Gets/sets the flag that instructs the engine whether to look for input files with relative names in the process's current directory before looking in [`RequiredInputDirectory`](../requiredinputdirectory/). Files with absolute names are opened directly regardless of this setting. Default value is `true`.

public bool SearchCurrentDirectory { get; set; }
