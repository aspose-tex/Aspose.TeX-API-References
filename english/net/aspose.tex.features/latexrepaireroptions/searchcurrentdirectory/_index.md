## LaTeXRepairerOptions.SearchCurrentDirectory property

Gets/sets the flag that instructs the engine whether to look for input files with relative names in the process's current directory and in the directory of the main input file before looking in [`InputWorkingDirectory`](../inputworkingdirectory/), [`RequiredInputDirectory`](../requiredinputdirectory/) and [`OutputWorkingDirectory`](../outputworkingdirectory/). Files with absolute names are opened directly regardless of this setting. Default value is `true`.

```csharp
public bool SearchCurrentDirectory { get; set; }
```
